# slide-agent

AI が HTML で作ったスライドを、ブラウザで直して、**PDF** と **PowerPoint で編集できる PPTX** に書き出すローカルアプリ（Mac）。

```
AI が deck.html を書く ──→ 画面で直す ──→ AI がさらに直す ──→ … ──→ PDF / PPTX
```

- 正本は資料ごとに `deck.html` 1つ。AI も人も同じファイルを直し、PDF・PPTX は毎回そこから作る
- 自分の Mac の中（`127.0.0.1`）だけで動く。資料は `private/` に入り、GitHub には上がらない
- AI（Claude Code）はこのフォルダの `CLAUDE.md` を読んで資料を作る。人が読むのはこの README だけでいい

## インストール

```bash
git clone https://github.com/sakuya714/slide-agent.git
cd slide-agent && ./install.sh
```

必要なもの：Mac・Homebrew・Google Chrome（PDF・PPTX の書き出しに使う）。AI に資料を作らせるなら Claude Code。`install.sh` が `private/`・`slide` コマンドを用意し、見本の資料「ようこそ / Slide Agent の紹介」を入れる（`slide` で開くと最初はこれだけある。読み終わったら消してよい）。

## 使い方

### AI に作ってもらう
このフォルダで Claude Code を開いて「〇〇の資料作って」と頼む。AI が `private/deck/` に資料を作り、チェックを通して、編集画面で開く。

### 自分で直す
```bash
slide                          # 編集画面を開く（最初は資料の一覧）
slide open 営業/〇〇社_提案      # その資料を開く
```

| 操作 | やり方 |
|---|---|
| 資料を選ぶ・作る | 左上の「‹」（⌘O）で一覧に戻る。左でフォルダを選ぶ。検索・「＋ 新しい資料」（選んでいるフォルダに作る）もここ |
| 部品を選ぶ | クリック（右パネルの上に「スライド3 › カード ›」と場所が出る。押すと親を選べる。Esc でも親へ） |
| 文字を直す | ダブルクリック／Enter（Enter で改行、Esc で終わる。⌘B 太字・⌘I 強調） |
| 色・大きさ・太さ・揃え | 右のパネル。選んだものに合わせて中身が変わる（何も選ばなければスライドの設定） |
| スライドを足す・複製・削除 | 左の列の上の「＋」「複製」「ごみ箱」。＋ はレイアウトを選ぶ（表紙・目次・区切り・カード3つ・手順・一覧・数字・項目と中身・左右・まとめ など） |
| 部品を足す | 上の「文字 ▾」「カード ▾」「画像」。選んだ部品のすぐ後ろに入る |
| 画像 | 上の「画像」、またはファイルをスライドにドラッグ・⌘V。画像の上に落とすと差し替え。`assets/` に保存される |
| 並べ替え | スライドは左の列か「一覧」（⌘G）でドラッグ／⌥↑↓。部品は右パネルの「前へ・後ろへ」／⌥↑↓ |
| 複製・コピー・削除 | ⌘D・⌘C／⌘V・⌫（右クリックのメニューでも）。部品は右パネルの上のボタンでも。スライドは別の資料にも貼れる |
| HTML を直接直す | 右クリック →「HTML を編集…」（部品・スライドごと。普段は使わない） |
| 元に戻す・やり直し | ⌘Z・⇧⌘Z（色・大きさを元のテーマの見た目に戻すのもこれ） |
| 発表者ノート | スライドの下の欄 |
| チェック | 上の「チェック」。文字のはみ出し・画像切れ・小さすぎる文字などを調べる。結果の一覧から押すとそのスライドへ飛び、左の列にも印が付く |
| 発表 | 上の「発表」（⌘Enter。最初からは ⇧⌘Enter）。N で発表者表示（ノート・次のスライド・経過時間）、B で黒い画面、Esc で終わる |
| PDF・PPTX | 上の「書き出し ▾」。保存のダイアログで保存先のフォルダとファイル名を選ぶ（前回のフォルダを覚えている。Chrome・Edge のとき。ほかのブラウザではダウンロードフォルダに入る） |
| 資料全体の色 | 何も選んでいないときの右パネルの一番下「資料全体の色…」 |
| 保存 | 自動（直して1秒後）。直前の版は `.deck.bak.html` に残る |

ショートカットの一覧は ⌘/。

AI がファイルを直すと、開いている画面に2秒以内に反映される。こちらに保存していない変更があるときは、どちらを残すか聞いてくる。

### コマンド
```bash
slide new   営業/〇〇社_提案      # 新しい資料 → private/deck/営業/〇〇社_提案/deck.html
slide check 営業/〇〇社_提案      # はみ出し・画像切れ・小さい文字などを調べる
slide pdf   営業/〇〇社_提案      # → ~/Downloads/〇〇社_提案.pdf（同じ名前があれば -2 を付ける）
slide pptx  営業/〇〇社_提案 -o ~/Desktop/   # -o で保存先のフォルダかファイル名を指定
slide stop / slide restart       # 裏で動くサーバーを止める／起動し直す
```

## 画面

```
資料の一覧（ホーム）
┌───────────────────────────────────────────────────────────┐
│ ▭ Slide Agent                         [⌕ 資料を探す] [＋ 新しい資料] │
├───────────────┬───────────────────────────────────────────┤
│ フォルダ         │ 営業 › 〇〇                         2 件      │
│ ▭ すべての資料 5 │ ┌──────┐ ┌──────┐                          │
│ ▢ サンプル    1 │ │      │ │      │                          │
│ ▢ 営業       4 │ └──────┘ └──────┘                          │
│   ▢ 〇〇     2 │ 〇〇社_提案  △△社_営業                        │
│   ▢ △△     2 │ 3分前      2日前                            │
└───────────────┴───────────────────────────────────────────┘

編集画面
┌──────────────────────────────────────────────────────────────────┐
│ ‹ 営業/〇〇社_提案 ●保存済み   ↶↷│文字▾ カード▾ 画像│一覧 94%▾   チェック ▶発表 [書き出し▾] │
├────────────┬─────────────────────────────────┬────────────────┤
│ 3/7 ＋ ⧉ 🗑 │                                 │ スライド3 › カード ›│
│ 1 ┌────┐   │ ┌─────────────────────────────┐ │ 見出し   ↑ ↓ ⧉ 🗑 │
│ 2 ┃    ┃   │ │                             │ │ 文字：色・大きさ・   │
│ 3 └────┘   │ │       編集中のスライド          │ │       太さ・揃え     │
│   …       │ └─────────────────────────────┘ │ 箱：背景色         │
│            │ ┌ ノート ───────────────────────┐ │（何も選ばなければ    │
│            │ └─────────────────────────────┘ │  スライドの設定）    │
└────────────┴─────────────────────────────────┴────────────────┘
```

- ホーム：左にフォルダの階層、右に選んだフォルダの資料（中のフォルダの資料も含めて更新順）。フォルダが増えても縦に伸びず、左の一覧が増えるだけ。前に選んだフォルダを覚えている
- 編集画面の上の帯：左＝一覧に戻る・いま開いている資料と保存状態／中央＝編集の道具（元に戻す・部品を足す・表示）／右＝確かめる・見せる・書き出す
- 左の列：スライドの枚数と、スライドを足す・複製・削除の3つだけ。並べ替えはドラッグ
- 右のパネルは「いま選んでいるもの」の書式だけを出す（PowerPoint の書式設定ウィンドウ、Keynote のインスペクタと同じ考え方）
- 資料全体のテーマ色は、普段は見なくていいので右パネルの一番下のボタンから開く。部品の色を選ぶときは、テーマ色が色見本として並ぶ
- 背景の写真と、それを暗くする幕は、クリックするとスライドが選ばれる（写真の差し替えはスライドの設定から）

## フォルダ構成

```
slide-agent/
├── README.md        人向けの説明（これ）
├── CLAUDE.md        AI 向けの説明（資料の作り方・コードを直すときの決まり）
├── bin/slide        slide コマンド（~/.local/bin/slide からリンク）
├── server/          裏で動くサーバー（Python / FastAPI）：保存・一覧・書き出しの受付、コマンドの中身
├── editor/          編集画面（HTML / CSS / JavaScript。ビルド不要）
├── theme/           資料のデザイン（default.css）・テーマ色の初期値（vars.css）・新しい資料のひな形（new.html）
├── export/          PDF・PPTX への変換とチェック（Chrome で資料を表示して処理する）
├── hooks/           private/ を commit させない見張り
├── welcome/         最初に入る見本の資料（ようこそ/Slide Agent の紹介）。install.sh が private/deck/ にコピーする
├── install.sh       セットアップ
└── private/         ← 自分だけ（GitHub に上がらない）
    ├── deck/          作業中の資料。{フォルダ}/{資料名}/deck.html と assets/（画像）。ホームのフォルダの階層になる
    └── rules/         自分で育てる AI への指示。共通.md は全資料、{フォルダ名}.md はそのフォルダの資料用（例：rules/営業.md）
```

## PPTX になるとき

| HTML | PowerPoint |
|---|---|
| 文字（見出し・段落・箇条書き） | テキストボックス（色・太さ・大きさを1文字単位で再現。箇条書きは PowerPoint の箇条書き） |
| 背景色・枠線・角丸のある箱、片側だけの線 | 図形 |
| 写真・画像 | 画像（トリミングも再現） |
| 図（SVG）・グラデーション・影・回転・表・角丸の写真 | その部分だけ画像になる（PowerPoint で文字を直せない。`slide check` が知らせる） |
| 発表者ノート | ノート |

- フォントは游ゴシック・游明朝に置き換わる（相手の PC にも入っているもの）
- PowerPoint は日本語の改行位置が Chrome と少し違うので、文字の箱は少し広げてある。1行の見出しは折り返さない
- PDF は画面と完全に同じ見た目（フォントも埋め込まれる）

## 仕組み

- **サーバー**：`slide` を打つと、裏で `127.0.0.1:8770` にサーバーが立つ（外からはつながらない）。ログは `~/Library/Logs/slide-agent.log`
- **編集画面**：資料を画面の中の iframe に読み込み、その HTML を直接いじる。選択中などの目印は保存するときに外すので、deck.html はいつもきれいなまま
- **外からの変更**：画面が2秒ごとにファイルの更新時刻を確認する。保存しようとしたときにファイルが変わっていたら、上書きせずに確認を出す
- **画像**：画面に落とした・貼った画像は、サーバーがその資料の `assets/` に保存し、`<img class="photo" src="assets/…">` として入る
- **発表**：保存前の内容も含めて、今の資料を全画面の iframe に読み込み、1枚ずつ見せる。ファイルは書き換えない
- **チェック**：`slide check` と同じもの（Chrome で資料を表示して調べる）を画面から呼ぶ
- **書き出し**：サーバーが一時フォルダに PDF・PPTX を作って画面に渡し、画面がブラウザの保存ダイアログ（File System Access API）で選んだ場所に書き込む。サーバー側には残さない
- **PDF**：Mac の Google Chrome を裏で動かして（Playwright）、1280×720 のページを1枚ずつ印刷する
- **PPTX**：Chrome で表示した資料から、部品ごとに位置・文字・色を読み取り（`export/extract.js`）、python-pptx で PowerPoint の部品に置き直す（`export/pptx.py`）

### 資料が GitHub に漏れない仕組み（2重）
1. `.gitignore` で `private/` を除外
2. pre-commit フック：`private/` の中のファイルが commit に入ったら止める（`git add -f` や書き間違いへの保険）

## これから

- **画面の中で AI に頼む**（スライド・部品を選んで「もっと短く」→ 裏で Claude Code が直す）
- 新しい資料を作るときに、`private/rules/` に合わせた型を選ぶ
- 資料の名前変更・削除を一覧から／文字の検索・置換／PNG 書き出し

作らないもの：
- 部品を好きな位置にドラッグで置く（PowerPoint のような自由配置）。HTML の並びが崩れて AI が直しにくくなり、はみ出しも起きやすい。並べ替えは「前へ・後ろへ」、大きさは右のパネルで
- 図形・矢印を描く道具・アニメーション。必要な図は AI に作らせる
- クラウド保存・共同編集／スマホでの編集／Google スライド・Keynote への書き出し／Web での公開
