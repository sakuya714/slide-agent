# slide-kit

AI が HTML で作ったスライドを、ブラウザで直して、**PDF** と **PowerPoint で編集できる PPTX** に書き出すローカルアプリ（Mac）。

```
AI が deck.html を書く ──→ 画面で直す ──→ AI がさらに直す ──→ … ──→ PDF / PPTX
```

- 正本は資料ごとに `deck.html` 1つ。AI も人も同じファイルを直し、PDF・PPTX は毎回そこから作る
- 自分の Mac の中（`127.0.0.1`）だけで動く。資料は `private/` に入り、GitHub には上がらない
- AI（Claude Code）はこのフォルダの `CLAUDE.md` を読んで資料を作る。人が読むのはこの README だけでいい

## インストール

```bash
git clone https://github.com/sakuya714/slide-kit.git
cd slide-kit && ./install.sh
```

必要なもの：Mac・Homebrew・Google Chrome（PDF・PPTX の書き出しに使う）。AI に資料を作らせるなら Claude Code。`install.sh` が `private/`・`slide` コマンドを用意する。

## 使い方

### AI に作ってもらう
このフォルダで Claude Code を開いて「〇〇の資料作って」と頼む。AI が `private/deck/` に資料を作り、チェックを通して、編集画面で開く。

### 自分で直す
```bash
slide                          # 編集画面を開く（☰ で資料の一覧）
slide open 営業/〇〇社_提案      # その資料を開く
```

| 操作 | やり方 |
|---|---|
| 部品を選ぶ | クリック（上に「スライド3 › カード › 見出し」と場所が出る。押すと親を選べる。Esc でも親へ） |
| 文字を直す | ダブルクリック（Enter で改行、Esc で終わる） |
| 色・大きさ・太さ・揃え | 右のパネル |
| 資料全体の色 | 右のパネルの「テーマ色」 |
| スライドの追加・複製・削除 | 左の一覧の上のボタン。並べ替えはドラッグ |
| 部品の複製・削除 | ⌘D・Delete（右パネルのボタンでも） |
| 元に戻す・やり直し | ⌘Z・⇧⌘Z |
| 発表者ノート | 下の欄 |
| 保存 | 自動（直して1秒後）。直前の版は `.deck.bak.html` に残る |
| PDF・PPTX | ☰ の一番下のボタン |

AI がファイルを直すと、開いている画面に2秒以内に反映される。こちらに保存していない変更があるときは、どちらを残すか聞いてくる。

### コマンド
```bash
slide new   営業/〇〇社_提案      # 新しい資料 → private/deck/営業/〇〇社_提案/deck.html
slide check 営業/〇〇社_提案      # はみ出し・画像切れ・小さい文字などを調べる
slide pdf   営業/〇〇社_提案      # → private/final/営業/〇〇社_提案.pdf
slide pptx  営業/〇〇社_提案      # → private/final/営業/〇〇社_提案.pptx
slide stop / slide restart       # 裏で動くサーバーを止める／起動し直す
```

## フォルダ構成

```
slide-kit/
├── README.md        人向けの説明（これ）
├── CLAUDE.md        AI 向けの説明（資料の作り方・コードを直すときの決まり）
├── bin/slide        slide コマンド（~/.local/bin/slide からリンク）
├── server/          裏で動くサーバー（Python / FastAPI）：保存・一覧・書き出しの受付、コマンドの中身
├── editor/          編集画面（HTML / CSS / JavaScript。ビルド不要）
├── theme/           資料のデザイン（default.css）・テーマ色の初期値（vars.css）・新しい資料のひな形（new.html）
├── export/          PDF・PPTX への変換とチェック（Chrome で資料を表示して処理する）
├── hooks/           private/ を commit させない見張り
├── install.sh       セットアップ
└── private/         ← 自分だけ（GitHub に上がらない）
    ├── deck/          作業中の資料。{フォルダ}/{資料名}/deck.html と assets/（画像）。サイドバーに出る
    ├── final/         完成品。書き出した PDF・PPTX（deck/ と同じ階層）
    └── rules/         自分で育てる AI への指示。直下は全資料共通、{フォルダ}/ はその資料用（例：rules/営業/提案書.md）
```

## PPTX になるとき

| HTML | PowerPoint |
|---|---|
| 文字（見出し・段落・箇条書き） | テキストボックス（色・太さ・大きさを1文字単位で再現。箇条書きは PowerPoint の箇条書き） |
| 背景色・枠線・角丸のある箱、片側だけの線 | 図形 |
| 写真・画像 | 画像（トリミングも再現） |
| 図（SVG）・グラデーション・影・回転・表・角丸の写真 | その部分だけ画像になる（PowerPoint で文字を直せない。`slide check` が知らせる） |
| 発表者ノート | ノート |

- フォントは游ゴシック・游明朝に置き換わる（相手の PC にも入っているもの）
- PowerPoint は日本語の改行位置が Chrome と少し違うので、文字の箱は少し広げてある。1行の見出しは折り返さない
- PDF は画面と完全に同じ見た目（フォントも埋め込まれる）

## 仕組み

- **サーバー**：`slide` を打つと、裏で `127.0.0.1:8770` にサーバーが立つ（外からはつながらない）。ログは `~/Library/Logs/slide-kit.log`
- **編集画面**：資料を画面の中の iframe に読み込み、その HTML を直接いじる。選択中などの目印は保存するときに外すので、deck.html はいつもきれいなまま
- **外からの変更**：画面が2秒ごとにファイルの更新時刻を確認する。保存しようとしたときにファイルが変わっていたら、上書きせずに確認を出す
- **PDF**：Mac の Google Chrome を裏で動かして（Playwright）、1280×720 のページを1枚ずつ印刷する
- **PPTX**：Chrome で表示した資料から、部品ごとに位置・文字・色を読み取り（`export/extract.js`）、python-pptx で PowerPoint の部品に置き直す（`export/pptx.py`）

### 資料が GitHub に漏れない仕組み（2重）
1. `.gitignore` で `private/` を除外
2. pre-commit フック：`private/` の中のファイルが commit に入ったら止める（`git add -f` や書き間違いへの保険）

## これから

- **画面の中で AI に頼む**（スライド・部品を選んで「もっと短く」→ 裏で Claude Code が直す）
- 新しい資料を作るときに、`private/rules/` に合わせた型を選ぶ
- 部品のドラッグ移動・サイズ変更／HTML の直接編集／画像のドラッグ＆ドロップ／発表モード／PNG 書き出し／チェック結果の画面表示

作らないもの：クラウド保存・共同編集／スマホでの編集／アニメーションの書き出し／Google スライド・Keynote への書き出し／Web での公開
