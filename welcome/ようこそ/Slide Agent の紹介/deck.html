02｜使い方Slide Agent

AI への頼み方

Claude Code をこのフォルダで開いて、ふだんの言葉で頼む

頼み方の例
AI がすること
「〇〇社向けの提案資料を10枚で作って」
新しい資料を作り、チェックを通して画面で開く
「3枚目をもっと短くして」
開いている資料を直す
「次から表紙に社名を入れて」
private/rules/ に決まりとして残し、次の資料から守る
「出す前に最終チェックして」
チェックに加えて、数字や言い回しを目でも確かめる

型（構成・デザイン・部品）は CLAUDE.md に、自分の決まりは private/rules/ に育てていく

Slide Agent05 / 11
rules は main.md（全部の資料）と {フォルダ名}.md（そのフォルダの資料）。

03｜書き出しと置き場所Slide Agent

PDF と PPTX の使い分け

見せるだけなら PDF、相手が直すなら PPTX

PDF

画面とまったく同じ見た目

  • フォントも埋め込まれる
  • メールで送る・印刷するときに
PPTX

PowerPoint で直せる

  • 文字・箱が PowerPoint の部品になる
  • 表紙の背景や図は画像になる

上の「書き出し」から選ぶ。保存の画面で、置く場所と名前を決める（名前は最初から資料の名前）

Slide Agent09 / 11
PPTX で画像になる部分は、チェックで「PPTX ではこの部分が画像になる」と出る。
