使い方

How to Use

Slide Agent7 / 14

使い方｜AI に頼む

AI への頼み方

Claude Code をこのフォルダで開いて、ふだんの言葉で頼む

「〇〇社向けの提案資料を10枚で作って」

新しい資料を作り、チェックを通して画面で開く

「3枚目をもっと短くして」

開いている資料を直す

「次から表紙に社名を入れて」

private/rules/ に決まりとして残し、次の資料から守る

Slide Agent8 / 14
AI は CLAUDE.md に書かれた型（構成・デザイン・部品）で資料を作る。自分好みの決まりは private/rules/ に育てていく。

使い方｜画面の見方

編集画面の見方

左の列スライドの一覧。上の ＋・複製・削除で足す・消す。ドラッグで並べ替え
上の帯文字・カード・画像を足す。発表・チェック・書き出し
真ん中クリックで選ぶ。ダブルクリックで文字を直す。右クリックでメニュー
右のパネル選んだものの色・大きさ・揃え。何も選ばなければスライドの設定
下の欄発表者ノート。発表者表示と PPTX のノートに出る
Slide Agent9 / 14
左上の「‹」で資料の一覧に戻る。

使い方｜よく使う操作

覚えておくと速い操作

迷ったら ⌘/ でショートカットの一覧を出す

⌘Z

元に戻す。色や大きさを戻すときも

⌘D

選んだ部品・スライドを複製

⌥↑ ⌥↓

部品・スライドを前後に動かす

⌘G

スライドを一覧で見る

⌘Enter

このスライドから発表

Esc

直し終わる・ひとつ外側を選ぶ

Slide Agent10 / 14
発表中は N で発表者表示（ノート・次のスライド・経過時間）、B で黒い画面。

書き出しと置き場所｜PDF と PPTX

PDF と PPTX の使い分け

見せるだけなら PDF、相手が直すなら PPTX

PDF

画面とまったく同じ見た目

フォントも埋め込まれる。メールで送る・印刷するときに。

PPTX

PowerPoint で直せる

文字・箱が PowerPoint の部品になる。表紙の背景や図は画像になる。

Slide Agent12 / 14

資料の置き場所
